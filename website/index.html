شويه اسئله اكيد جت في بالك

هل 3ameiah بتترجم الكود؟

لأ. هي بتظبط الكلام اللي الإنسان بيقراه، وتحافظ على الكود والـURLs والـplaceholders وأسماء الـAPIs زي ما هي.

هل ينفع أستخدمها في أي حاجة؟

تنفع في المواقع، الرسائل، البوستات، السكريبتات، الدروس، المستندات وحاجات تانية. الـSkill بتتكيّف مع نوع الشغل بدل ما تحوّله لقالب كتابة واحد.

هي مجانية؟

المشروع Open Source برخصة MIT، وموجود على GitHub وnpm. أي تكلفة موديل أو Agent بتفضل حسب الأداة اللي إنت مستخدمها.

ليه الاسم في Codex بيبدأ بـ$ بدل /؟

كل Agent ليه طريقة استدعاء Skills. Claude Code بيستخدم /3ameiah، وCodex بيستخدم $3ameiah. اسم الـSkill نفسه ثابت.
